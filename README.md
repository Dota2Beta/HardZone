# HardZone

Учебный интернет-магазин по продаже компьютеров на чистом PHP + MySQL + Bootstrap/CSS/JS.

## Что реализовано
- Регистрация пользователя: email, пароль, повтор пароля, логин, телефон, капча.
- Авторизация/выход.
- Профиль пользователя с редактированием: логин, email, телефон, пароль, аватар (загрузка из файла) + капча.
- Каталог компьютеров.
- Админ-панель для управления товарами (добавление, редактирование, удаление).
- В админке загрузка фото товара из файла (вместо URL).
- Корзина и оформление заказа с выбором способа оплаты.
- Форма обратной связи с капчей + просмотр сообщений в админке.

## Быстрый запуск
1. Создайте БД и таблицы:
   ```bash
   mysql -u root -p < sql/schema.sql
   ```
2. При необходимости поправьте доступ к БД в `src/config.php`.
3. При запуске не из корня сайта укажите базовый префикс в `BASE_URL` в `src/config.php`.
4. Запустите локальный сервер:
   ```bash
   php -S 0.0.0.0:8080 -t public
   ```
5. Откройте: `http://localhost:8080`
